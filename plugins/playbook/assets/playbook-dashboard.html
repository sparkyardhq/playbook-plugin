Queue ·

how this works

The plans tab lists every open implementation plan with its tasks by status — done, in progress, queued, paused — and a pause / bring back button on each task; the same button sits on the tasks and defects rows and on the tree rows. Every open task (or defect) is here: the prioritised ones first, by priority (top, high, medium, low), then the unranked ones in a last band. Inside one band the order is yours: the arrows move a record up or down among its equals, the double arrow puts it first; to move it across priorities, change its priority. Each move is one word to the Board.
